# DevCapa

Developer portfolio website with apps showcase and blog.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Mantine UI
- **Deployment**: GitHub Pages (static export)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Static files are exported to `out/` directory.
